# Rock Paper Scissors Game

An interactive Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## About
This is a simple browser-based game where you play Rock, Paper, Scissors against the computer. 
This project was created to practice GitHub and web development fundamentals.

## Technologies Used
- **HTML5** - Game structure
- **CSS3** - Styling and layout
- **JavaScript** - Game logic and user interaction

## How to Play
1. Open `index.html` in your web browser
2. Click on Rock, Paper, or Scissors
3. See who wins - You or the Computer!
4. Your score will be tracked on the screen

## Features
- Interactive gameplay
- Score tracking
- Responsive design
